# ♟ Xadrez

Jogo de xadrez acadêmico em **C# / .NET 8**, agora com uma interface de terminal jogável.

## Recursos
- Tabuleiro 8×8 com peças Unicode.
- Turnos alternados entre brancas e pretas.
- Movimentos básicos de peões, torres, cavalos, bispos, dama e rei.
- Capturas.
- Reinício com `R`.
- Saída com `S`.
- Interface com HUD e feedback de jogadas.

> Projeto acadêmico focado em lógica, estruturas e programação em C#. A implementação é uma versão didática e não pretende substituir um motor completo de xadrez: ainda não valida xeque, xeque-mate, roque ou en passant.
